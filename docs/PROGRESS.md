## M0 — هيكل المستودع

الحالة: مكتملة

معايير القبول:

- [x] كل أوامر القسم (ب) تنجح على نسخة نظيفة — نجح تثبيت الاعتمادات من ملف القفل على نسخة Git نظيفة. نجح `pnpm db:up` بإعداد Compose الافتراضي بعد بناء MinIO من المصدر المثبّت. أظهر Compose أن PostgreSQL 18.7 وMinIO في حالة `healthy`، وأعاد فحص جاهزية MinIO الحالة `200`. نجح `pnpm db:migrate` و`pnpm db:seed` بلا عمل. اكتمل تسلسل `pnpm lint && pnpm typecheck && pnpm test && pnpm build` من جذر نسخة التحقق.
- [x] `GET /health` يعيد 200 ويفحص الاتصال بالقاعدة — أعاد طلب HTTP مباشر `200` مع `{"status":"ok"}` على PostgreSQL من Compose. نجح اختبارا `apps/api/test/health.test.ts` على القاعدة نفسها، وشملا رفض الاتصال بقاعدة غير موجودة بحالة `503`.

نتائج الأوامر: lint ✓ · typecheck ✓ · test ✓ (12) · build ✓

أسئلة مفتوحة: توقيت قيد العمولة عند التسليم، وتفويض إعادة انتقال الطلب، وصلاحية تغيير توفّر خيارات المنيو، وتباين الأيقونات. التفاصيل والمقترحات في [الأسئلة المفتوحة](OPEN_QUESTIONS.md).

الحالة: مكتملة

- [x] تقريب عمولة `33333` عند `1000` نقطة أساس إلى `3333` — `packages/domain/test/money.test.ts`.
- [x] السماح بكل صف في جدول الانتقالات ورفض كل زوج غير مذكور — `packages/domain/test/order-state.test.ts` يولّد 2,000 تركيبة من الحالات والفاعلين وأنواع الطلب.
